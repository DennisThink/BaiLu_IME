# BaiLu_IME
An input method based on Text Service Framework on windows.

Relay on the following projects.

1. [BaiLuIME_Common](https://github.com/DennisThink/BaiLuIME_Common) 

provide some basic common functions and common struct.

2. [BaiLuIME_CandidateGenerator](https://github.com/DennisThink/BaiLuIME_CandidateGenerator)

read pinyin and chinese candidate from the file and give candidates by the pinyin.

3. [BaiLuIME_CandidateServer](https://github.com/DennisThink/BaiLuIME_CandidateServer)

give candidates by TCP server 

4. [BaiLuIME_CandidateWindow](https://github.com/DennisThink/BaiLuIME_CandidateWindow)

the candidate Window of BaiLuIME.
